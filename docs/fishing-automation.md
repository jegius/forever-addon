# Рыбалка: можно ли «безопасно» автоматизировать?

Короткий ответ: **нет.** Гипотеза «рыбалка безопасна, потому что персонаж стоит на месте» неверна.
Автоматическая рыбалка — это бот, а не аддон: она невозможна средствами WoW API, а внешняя
автоматизация запрещена и приводит к блокировке аккаунта.

## 1. Почему аддон не может рыбачить сам

| Шаг | API | Вердикт |
| --- | --- | --- |
| Забросить удочку | `CastSpellByName` / `UseAction` | protected, только secure-кнопка или `/cast` |
| Увидеть поплавок и поклёвку | нет API | аддон не видит мир, звук и экран; события «поклёвка» нет |
| Кликнуть по поплавку | нет API | взаимодействие с объектом мира не экспонируется |
| Нанести приманку/снасть | `C_Container.UseContainerItem` | protected |
| Выйти при полном инвентаре | `Logout()` | protected с 7.3.2 |
| Движение/позиционирование | `MoveForwardStart` и т. п. | protected + hardware event |

Даже если аддон отслеживает каст (`UNIT_SPELLCAST_SENT`/`SUCCEEDED`) и лут (`LOOT_OPENED`), он
узнаёт о результате **после** действия игрока. Нажать за игрока он не может.

Ссылки: [CastSpellByName](https://warcraft.wiki.gg/wiki/API:CastSpellByName),
[Logout](https://warcraft.wiki.gg/wiki/API:Logout),
[Fishing](https://warcraft.wiki.gg/wiki/Fishing) (поплавок нужно кликнуть вручную),
[UseContainerItem](https://warcraft.wiki.gg/wiki/API:C_Container.UseContainerItem).

## 2. Почему «стоять на месте» не делает бота незаметным

Наоборот, стационарная рыбалка — один из самых простых паттернов для детекта:

- идеально повторяющиеся интервалы каста/клика, без человеческого разброса;
- многочасовые сессии без движения, чата, смены локации;
- одинаковое соотношение кастов/пойманной рыбы, аномально ровный «аптайм»;
- один и тот же персонаж/место/время суток;
- клиентские античит-системы видят сторонний процесс/инъекцию ввода, а не «умность» бота;
- другие игроки видят персонажа, который часами рыбачит без реакций, и жалуются.

Blizzard не раскрывает эвристики, но прямо говорит, что они постоянно улучшаются, а баны приходят
волнами. В официальном сообщении — **более 74 000 закрытых/приостановленных аккаунтов за месяц**,
«в основном за инструменты автоматизации игрового процесса, обычно для фарма ресурсов»
([Actions Taken to Address Exploitative Gameplay](https://us.forums.blizzard.com/en/wow/t/actions-taken-to-address-exploitative-gameplay/558339)).

Политика: EULA прямо запрещает ПО, не разрешённое Blizzard, которое «changes and/or facilitates the
gameplay», а также автоматизацию; наказание — вплоть до постоянного закрытия аккаунта
([Prohibitions on Third-party Software](https://us.forums.blizzard.com/en/wow/t/prohibitions-on-third-party-software/2142972),
[UI Add-On Development Policy](https://us.forums.blizzard.com/en/wow/t/ui-add-on-development-policy/24534)).

Вывод: «безопасного» бота для рыбалки нет. Чем проще и однообразнее процесс, тем легче он
детектируется — и тем выше шанс потерять аккаунт.

## 3. Почему нейросеть не меняет ситуацию

- Локальная LLM (Qwen3 4B/8B и т. п.) не запускается внутри аддона: у Lua-песочницы нет сети,
  файлов и ОС.
- Внешняя программа, которая смотрит на экран, распознаёт поплавок и эмулирует клики, — это
  классический бот. Наличие нейросети не делает его легальным.
- Для реального времени нужна CV-модель и инъекция ввода; LLM 4B для этого не подходит и всё равно
  не отменяет бан.
- Легально LLM может лишь **после сессии** разобрать экспортированную статистику и подсказать
  места/время/приманки.

## 4. Что можно сделать легально: Fishing Assistant

Безопасная версия аддона, которая помогает, но не играет:

- статистика сессии: забросы, поклёвки, улов, рыба/мусор, улов в час, время, зона;
- журнал улова и экспорт для анализа (в т. ч. локальной LLM после игры);
- счётчик свободных слотов и предупреждение «сумки полны»;
- напоминание про `/logout` и безопасное место (`IsResting()`), без автовыхода;
- таймер с момента заброса (не детект поклёвки — это честно и законно);
- учёт приманок/снастей вручную или по событию применения (если API отдаёт событие — проверить);
- память мест рыбалки/косяков (по аналогии с узлами ресурсов);
- подсказки по уровню навыка и зонам.

Это ускоряет рыбалку за счёт информации, но каждое действие делает игрок.

## 5. Что делать дальше

Если нужен именно помощник — можно добавить модуль `Fishing.lua` в проект (v0.5):
трекер сессии + предупреждение о сумках + экспорт статистики. Никаких автозабросов, автокликов,
автоприманок и автовыхода.
