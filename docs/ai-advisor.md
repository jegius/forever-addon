# Безопасный AI-советник

## Границы

Советник **не управляет игрой**:

- не кликает, не эмулирует ввод, не читает экран/память;
- не делает HTTP-запросов из аддона;
- не содержит API-ключей;
- не обещает гарантированную прибыль.

Аддон собирает агрегированный снимок рынка, а анализ/диалог выполняет внешний локальный агент
(MCP/LLM) уже после `/fa export`.

## Поток данных

```text
WoW addon
  /fa scan + /fa detail
  /fa export
    -> SavedVariables: ForeverAddonDB.exportJson
    -> локальный MCP/агент
    -> отчёт: health, flips, craft plan, professions, farming, explain
```

`/fa export` не пишет файлы и не отправляет данные в сеть. JSON лежит в SavedVariables и доступен
только локально.

## Встроенный советник

`/fa advice` (или кнопка «Советник» на вкладке скана) выводит:

- свежесть скана и покрытие рецептов;
- топ флипов с confidence;
- риски и guardrails.

Это детерминированный rule-based помощник; он не является LLM, но даёт безопасный baseline.

## Инструменты внешнего агента

| Инструмент | Назначение |
|---|---|
| `market_health` | свежесть, покрытие, аномалии |
| `top_flips` | прибыль, ROI, confidence, риск |
| `craft_plan` | что купить/скрафтить/продать под бюджет |
| `profession_advice` | какую профессию качать |
| `farming_plan` | зоны/ресурсы, доход/час |
| `explain` | формула и допущения |

## Guardrails

- Всегда диапазон/confidence, не «гарантированная прибыль».
- Помечать мало истории, мало лотов, демпинг, устаревший скан.
- Не рекомендовать автоматизацию, обход античита, мультибоксинг.
- Не отправлять персональные данные; только агрегаты цен.

## Как подключить локальный агент

1. В игре: `/fa scan`, при необходимости `/fa detail`, затем `/fa export`.
2. Взять `ForeverAddonDB.exportJson` из SavedVariables.
3. Передать JSON локальному MCP/LLM с системным промптом: «аналитик аукциона, не давай гарантий,
   указывай confidence и риски».
4. Агент возвращает текст/таблицу; игрок сам принимает решения.

Пример безопасного запроса:

```text
У меня 500g. Проанализируй export.json: какие 3 флипа/цепочки выбрать, какой риск,
что делать, если лот исчез. Не давай гарантий, покажи допущения.
```

## Почему не встроенный LLM в аддоне

WoW Lua не имеет HTTP/сокетов, а внешние вызовы из игрового процесса — это уже не аддон.
Локальный MCP/LLM вне игры сохраняет безопасность и не требует ключей в SavedVariables.
